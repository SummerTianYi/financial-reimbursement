# 澄序财务｜报销管理系统 HTML 交互原型

这是一个**单文件、无构建步骤**的 Web 交互原型。`index.html` 包含全部样式、页面和脚本，无需 npm 依赖，可直接部署到 Vercel，电脑和手机浏览器均可使用。

> ⚠️ **只用于演示和需求验收，不可用来处理真实财务业务。** 当前账号密码验证、角色切换、访问控制、操作日志和重复报销检查都发生在浏览器端；数据不在服务器共享，也不能阻止有人修改浏览器本地的数据。请勿录入真实银行收款账号、密码或上传真实票据。

## 页面与功能

- **员工**：新建报销单、多笔费用明细、逐笔上传 JPG/PNG/WebP/PDF、草稿、提交、撤销、查看审核意见、退回重提、报销记录。
- **审核员**：只看到演示数据中分配给自己的申请；查看详情及票据；通过或填写意见后退回。
- **财务**：查看已审核待报销单据；多选创建唯一批次；阻止有效批次中的单据被重复归集；导出真正的 `.xlsx` 汇总表和明细表（含财务专用收款信息）；批量确认线下打款；查看历史与统计。
- **管理员**：账号角色与部门配置、默认审核员、报销类别、操作日志。
- **金额**：输入时验证两位小数，业务汇总在 JavaScript 中使用**整数分**，Excel 中以带两位小数格式的数值写入。
- **附件**：只在当前浏览器 IndexedDB 中存储；业务数据保存在 localStorage，登录状态保存在 sessionStorage。

## 本地打开

双击 `index.html` 可以预览。为减少浏览器对 `file://` 的存储限制，也可在目录下运行：

```bash
python -m http.server 8080
```

然后打开 `http://localhost:8080/`。

## 部署 Vercel

推荐通过 GitHub，无需构建：

1. 创建 GitHub 仓库，将 `index.html`、`vercel.json` 上传到**仓库根目录**。
2. 登录 [Vercel](https://vercel.com/)，点击 **Add New → Project → Import Git Repository**。
3. Framework Preset 选择 **Other**，Root Directory 为 `./`；**无需填写 Build Command、Install Command**。
4. 点击 **Deploy**，生成的 `*.vercel.app` 网站即可访问。

也可用已登录 Vercel CLI 在该文件夹下运行 `vercel --prod`。

## 与正式系统的差异

- **无真正账号认证、后端权限验证和密码哈希**：演示密码写在前端代码里，不构成安全保护。
- **无共享数据库和并发事务**：不同浏览器、设备之间的操作不会同步；重复报销检查不能抵御多人同时操作。
- **无服务端附件存储、授权下载、病毒扫描与备份**：附件仅存当前浏览器、无法跨设备查看。
- **无实际银行支付**：确认按钮只变更原型内的状态。
- **无后端审计不可篡改性与敏感信息加密**。

要投入真实使用，建议保留当前视觉方案，接入后端 API、数据库（如 PostgreSQL）、服务端认证与角色权限、对象存储、数据库级唯一有效批次约束、原子状态事务及备份。**仅把这个 HTML 部署到 Vercel 并不能满足正式财务系统的安全要求。**
